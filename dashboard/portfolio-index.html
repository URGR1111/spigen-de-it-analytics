유럽 시장에서 예산과 수요가 어긋나는 지점을, 데이터로 찾아봤습니다

독일·이탈리아 두 시장을 실측 데이터로 조사하고, 문제를 원인 단위로 쪼개고, 합성 데이터로 직접 검증한 뒤, 운영 도구까지 설계했습니다. 아래 4단계는 제가 이 문제를 실제로 풀어간 순서 그대로입니다.

이 포트폴리오로 보여드리고 싶은 것 3가지

01

데이터를 직접 다뤄본 경험

Statcounter·Google Trends·Meta·TikTok·Amazon에서 실측 데이터 5종을 직접 수집했고, Python으로 30,000명 규모 합성 고객 데이터 파이프라인을 처음부터 설계·구현했습니다.

02

진출 시장(유럽)에 대한 깊은 고민

독일과 이탈리아를 같은 유럽이라고 뭉뚱그리지 않고, 기기 구성·검색 습관·구매 시즌이 다르다는 걸 실측으로 규명하고 시장별로 다른 전략을 설계했습니다.

03

실제 분석 역량

회귀·상관분석, RFM, 코호트 리텐션, A/B 테스트, K-Means, Prophet 시계열 예측을 직접 수행하고, 그 결과를 의사결정으로 이어지는 화면으로 설계했습니다.
