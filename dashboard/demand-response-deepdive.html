합성 데이터 · 회귀분석

원인① Plan 경직성 — 지출은 수요와 사실상 무관하게 편성된다

주간 광고비(spend_eur)를 주간 수요지수(demand_index)에 단순회귀했습니다. 점 하나가 한 주입니다. 기울기가 0에 가깝고 R²가 매우 낮을수록 "계획이 수요를 반영하지 않는다"는 증거입니다.

x축: 주간 수요지수, y축: 주간 광고비(€). 점선은 최소자승 회귀선입니다.

효율조정 배분지수 (EAI)

실제 배분 vs 균등 배분 시 ROAS 가중 효율 비교

EAI = Σ(주간 지출 비중 × 그 주 첫구매 ROAS). 실제 배분이 균등 배분과 거의 같다는 것은, 예산이 효율 높은 주로 몰리지 않고 있다는 뜻입니다.
회귀계수가 오히려 음수

DE 표준화 베타 -0.18, IT -0.03. 수요가 높을수록 지출이 소폭 줄어드는 방향입니다. 우연한 잡음 수준이지만, 최소한 "수요가 늘면 지출도 는다"는 관계는 전혀 없습니다.

EAI 격차 DE -0.55%p, IT -0.27%p

지금 배분 방식이 만드는 효율은 "아무 생각 없이 균등하게 뿌렸을 때"와 사실상 같습니다. 수요·효율 정보를 계획에 반영하는 것만으로 개선 여지가 있다는 뜻입니다.

합성 데이터 · 상관분석

원인② Execute 경직성 — 시장 신호는 있는데 집행이 못 따라간다

수요지수·CTR·CPC를 각각 연평균=100으로 지수화해 한 화면에 겹쳤습니다. CTR(클릭률)은 수요를 따라 움직이는데, 정작 지출은 앞서 본 것처럼 평평합니다.

CTR-수요지수 상관계수: DE 0.79 / IT 0.88 (강한 양의 상관). CPC-수요지수 상관계수: DE -0.82 / IT -0.89 (강한 음의 상관 — 피크 시즌에 클릭이 오히려 저렴해짐).

수요 최상위 vs 최하위 5분위 — 증가율 비교

같은 5분위 구간에서 수요는 크게 뛰는데 지출은 거의 안 뛰거나(IT) 오히려 줄어듭니다(DE).

데이터 출처와 방법
  1. data/raw/marketing_spend.csv (일별 채널·국가 광고비·노출·클릭) → 주간 집계
  2. data/raw/dim_calendar.csv (실측 Google Trends 기반 일별 수요지수) → 주간 평균
  3. data/raw/orders.csv, users.csv → 채널별 첫구매 매출, CAC, LTV(누적 순매출) 산출
  4. 탄력성(β)·R²는 numpy 최소자승 회귀, 상관계수는 피어슨 상관 (scipy 미사용, numpy corrcoef 직접 계산)

모든 수치는 spigen-synthetic-data 합성 데이터(seed=42, 고객 30,000명) 분석 결과입니다. 실제 슈피겐 데이터가 아니며, 마지막 미완결 주(2026-08-30 시작)는 표본이 작아 차트에서 제외했습니다.
