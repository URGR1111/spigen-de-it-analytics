방법론 · 사용 기술

이 분석에서 실제로 쓴 도구

데이터 생성

Python, pandas, numpy, Faker(de_DE/it_IT 로케일)로 고객 3만 명·주문 5.5만 건·이벤트 190만 건을 생성했습니다. 계절성은 실측 Google Trends 지수로 가중했습니다.

적재·집계

SQLite + 순수 SQL로 품질 점검, RFM, 코호트 리텐션, A/B, 수요-예산 집계 쿼리 5종을 작성했습니다. MySQL 8.0 버전 쿼리도 별도로 검증했습니다.

통계·머신러닝

scikit-learn K-Means(+ numpy 자체 구현 대체 경로), Prophet 시계열 예측, 정규근사·부트스트랩 기반 A/B 유의성 검정을 python으로 직접 구현했습니다.

시각화

matplotlib로 색맹 친화 팔레트를 적용한 EDA·클러스터·예측 그림을 그리고, 이 대시보드는 순수 HTML/CSS/SVG로 직접 구현했습니다(차트 라이브러리 미사용).

데이터 품질

고아 레코드, 금액 불일치, 가입 전 주문 등 7종 무결성 규칙을 점검한 결과 위반 0건이었습니다.
